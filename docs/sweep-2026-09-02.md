## Method

Eight sweepers and eight refuters, sixteen agents, read-only, sharing the live tree; every
behavioural claim driven from `createBoard({fresh:true})` (or the board's own opening where
that board takes no `fresh` flag — `/dawnspur-dispatch/` and `/dawnspur-storm/` do not) through
the board's own commit functions. Where a claim was about a killed build, the killed bytes
were extracted by `git show` and their sha re-checked against `KILLS.md` before driving them.
The synthesis then kept CONFIRMED and PARTIAL rows whose refuter agreed the action, dropped
disputed-action rows into *do not average*, deduplicated across sections, built one anchored
edit set (anchors **cut** from the file by line range, never retyped, refused unless unique
and non-overlapping), and put rows only the refuter proposed into a separately labelled set.

**Three things this sweep did that §6's did not, all forced by the subject matter.**

1. **Line-number self-citations were stripped from every replacement.** The parentheticals
   naturally want to say "§7 at `:248`". Eighteen such cites were written and then removed in
   favour of section names and quoted phrases, because the edit set moves the file by 154
   lines and every one of them would have been wrong on landing — the same defect the sweep
   is correcting, manufactured by the correction. What remains are cites into *other* files,
   which do not move. This is `CLAUDE.md`'s "do not re-type a number into this file" applied
   to a file no test grades.
2. **Cross-section dedup was load-bearing, not bookkeeping.** Three findings were reached
   twice from different sections, and one pair would have contradicted each other if both had
   landed. See *Dispositions*.
3. **Every replacement's own quotations were graded by the standard the sweep is enforcing.**
   Two of them failed it and were fixed before the dry run: the Core Loop sentence proposed as
   the fix for `:195` and the one proposed for `:180` were both prefix quotes closed without an
   ellipsis — the defect of findings 5 and 10, reproduced inside their own corrections. Both
   now carry the ellipsis. This is the check `s7.5`'s refuter caught its sweeper failing inside
   the row about prefix quoting, and it is worth running on any edit set this file produces.
